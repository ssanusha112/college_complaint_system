# Project Description

A web-based **College Complaint System** developed using **Python Flask** and **MySQL**. The system allows students to submit complaints related to college activities, facilities, academics, and other issues. Administrators can view, manage, and respond to complaints through a secure dashboard.

---

# Technologies Used

* Python
* Flask
* MySQL
* HTML
* CSS
* XAMPP

---

# Main Features

* Student Registration
* Secure Login
* Complaint Submission
* Complaint Dashboard
* View Complaint Status
* Edit Complaints
* Delete Complaints
* Admin Complaint Management
* MySQL Database Integration
* User-Friendly Interface

---

# Project Purpose

The purpose of this project is to provide a simple and efficient digital platform for students to submit and track their complaints. It reduces manual complaint handling and helps college administrators manage student issues in an organized way.
